# Scratch 通知チェッカー

Scratchの公開APIで「通知数」だけを約60秒ごとに確認し、通知数が増えたときにブラウザのデスクトップ通知を表示する静的Webページです。

- ブラウザ拡張機能やデベロッパーモードは不要です。
- Scratchのパスワード、ログインCookie、通知本文、送信者名は入力・取得しません。
- 監視を続けるにはページを開いておく必要があります。ページやブラウザを閉じると監視は止まります。
- 初回は現在の通知数を基準として保存するため、起動前からある通知は通知しません。次回以降は前回保存した件数と比較します。
- 通知数APIやScratch側の仕様変更で動作しなくなる場合があります。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成します（例：`scratch-notifier-web`）。公開リポジトリで構いません。このページは個人情報や秘密情報を含みません。
2. このフォルダーの `index.html` をリポジトリの最上位にアップロードし、コミットします。
3. リポジトリの **Settings → Pages** を開き、Build and deployment で **Deploy from a branch** を選びます。
4. Branch を `main`、フォルダーを `/(root)` にして **Save** を押します。
5. GitHub Pagesが表示した `https://<ユーザー名>.github.io/<リポジトリ名>/` のURLを開きます。
6. Scratchユーザー名を入力し、**通知チェックを開始** を押します。Chromeが尋ねたら通知を許可します。
7. **通知テスト** を押して、通知が表示されるか確認します。
